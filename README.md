# Tinman

Robot-view multi-project workbench. The runnable React + TypeScript demo lives in [`demo/`](demo/).

## Run the demo

```bash
cd demo
npm install
npm run dev
```

Open the URL printed by Vite (default `http://localhost:5173`).

## Build and test

```bash
cd demo
npm test
npm run build
```

## Sources

- Visual reference: `robot-v2.html`
- Assumptions recorded during the demo build: `demo/ASSUMPTIONS.md`
